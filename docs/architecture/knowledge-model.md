# Knowledge Model

## Core Objects

-   Source: Original document or URL.
-   Evidence: Supporting passage with citation.
-   Claim: Atomic factual assertion.
-   Topic: Semantic grouping.
-   Entity: Person, place, organization, concept.
-   Relation: Directed link between entities or claims.
-   Contradiction: Two incompatible claims with supporting evidence.

Claims connect to Topics, Entities and Evidence. Relations create the
knowledge graph.
